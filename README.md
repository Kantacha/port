# E-Portfolio | กันตชา แพงป้อง

แฟ้มสะสมผลงาน (E-Portfolio) ของนางสาวกันตชา แพงป้อง
เพื่อประกอบการสมัครเข้าศึกษาต่อ **มหาวิทยาลัยศิลปากร คณะโบราณคดี สาขาประวัติศาสตร์ศิลปะ**

🌐 เว็บไซต์: `https://ชื่อผู้ใช้.github.io/ชื่อ-repository/` *(แก้เป็นลิงก์จริงหลังเผยแพร่)*

## เนื้อหาในเว็บไซต์

| ส่วน | รายละเอียด |
|------|-------------|
| หน้าแรก | แนะนำชื่อ ข้อความต้อนรับ และปุ่มเปิดผลงานบน GitHub |
| แนะนำตัว | ประวัติ การศึกษา และความสนใจ |
| ผลงาน | ผลงานที่เกี่ยวข้องกับประวัติศาสตร์ ศิลปะ และโบราณคดี |
| กิจกรรม | กิจกรรมและประสบการณ์เรียงตามลำดับเวลา |

## คุณสมบัติ

- ไฟล์เดียว `index.html` ใช้ HTML, CSS และ JavaScript ล้วน ไม่ต้องติดตั้งเครื่องมือเพิ่ม
- โทนสีเขียว ใช้ฟอนต์ TH Sarabun New (ฟอนต์มาตรฐานราชการไทย) โดยโหลด Sarabun จาก Google Fonts เป็นตัวสำรอง
- รองรับมือถือและคอมพิวเตอร์ (Responsive Design)
- มีเมนูนำทางและปุ่มไปยัง GitHub

## วิธีเปิดดูในเครื่อง

ดาวน์โหลด `index.html` แล้วดับเบิลคลิกเปิดในเบราว์เซอร์ได้ทันที

## วิธีเผยแพร่ผ่าน GitHub Pages

1. สร้าง repository ใหม่บน GitHub (ตั้งเป็น Public)
2. อัปโหลดไฟล์ `index.html` และโฟลเดอร์ `images` (ถ้ามี) ไว้ที่ราก (root) ของ repository
3. ไปที่ **Settings → Pages**
4. ที่ Source เลือก **Deploy from a branch** แล้วเลือก branch `main` และโฟลเดอร์ `/ (root)` จากนั้นกด **Save**
5. รอประมาณ 1–2 นาที แล้วเปิดลิงก์ที่ GitHub แสดงไว้

## วิธีแก้ไขข้อมูล

ข้อมูลทั้งหมดอยู่ในก้อน `const DATA = {...}` ใกล้ท้ายไฟล์ `index.html` แก้เฉพาะตรงนี้ได้เลย

| ตัวแปร | ใช้ทำอะไร |
|--------|-----------|
| `github` | ลิงก์ GitHub ของคุณ |
| `photo` | path รูปโปรไฟล์ เช่น `"images/profile.jpg"` |
| `heroSub`, `heroText` | ข้อความในหน้าแรก |
| `about` | ข้อความแนะนำตัว |
| `facts` | ข้อมูลโรงเรียน เกรด อีเมล ฯลฯ |
| `interests` | ความสนใจ |
| `works` | ผลงาน แต่ละชิ้นประกอบด้วย `title`, `desc`, `link`, `tag` |
| `activities` | กิจกรรม แต่ละรายการประกอบด้วย `date`, `title`, `desc` |
| `footer` | ข้อความท้ายหน้า |

ข้อความในวงเล็บเหลี่ยม `[ ]` เป็นข้อมูลตัวอย่าง ต้องแทนด้วยข้อมูลจริง

**เพิ่มผลงาน:** คัดลอกบรรทัดผลงานหนึ่งรายการ (`{title: ..., desc: ..., link: ..., tag: ...},`) แล้ววางต่อท้ายในรายการ `works`

**เปลี่ยนสี:** แก้ตัวแปร `--green-900`, `--green-700`, `--green-500` ฯลฯ ในส่วน `:root` ของ CSS
